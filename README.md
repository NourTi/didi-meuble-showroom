# Didi Meuble — Premium Furniture Commerce Demo

> **A free, independently developed demo concept by NourTi for Didi Meuble, El Oued, Algeria.**

[Open the live interactive demo](https://didimeuble-ipu7l4nk.manus.space/?code=fWREsZXgxFrocEhS9CkZzE) · [View the GitHub Pages presentation](https://nourti.github.io/didi-meuble-showroom/)

## The idea

Didi Meuble already has a strong craft identity, authentic work, and an engaged social audience. This project turns that potential into a digital showroom: a product-led, Arabic-first experience that can present furniture clearly, capture delivery inquiries from afar, and give the owner a foundation for e-commerce growth.

The first version is offered as a **free visual and commercial concept**. There is no expectation of payment now. If the direction resonates with Didi Meuble, the next phase can evolve it into a complete remote-selling channel with a verified catalog, real pricing, delivery configuration, payment options, and customer follow-up.

## What is included

| Area | Included in the demo |
| --- | --- |
| Brand experience | Authentic Didi logo, El Oued atelier story, Arabic-first design, French toggle |
| Product discovery | Room-first navigation, premium catalogue hierarchy, featured furniture realization |
| 3D interaction | Locally bundled Three.js material study for bedrooms, sofas, and children’s rooms |
| Delivery inquiries | Product request modal, quantity, wilaya, commune, address, validation, throttling, owner alert |
| Owner tools | Role-gated catalogue and inquiry overview |
| Reliability | SEO metadata, JSON-LD, sitemap, robots policy, security headers, tests |

## Live demo and technical scope

The complete application is deployed at the live demo link above. It contains a server, database, protected owner tools, and secure inquiry handling. **GitHub Pages cannot run that backend**, so this repository includes a polished static presentation under `docs/` that directs visitors to the full interactive demo.

## Run locally

```bash
pnpm install
pnpm dev
```

Run validation with:

```bash
pnpm check
pnpm test
pnpm build
```
